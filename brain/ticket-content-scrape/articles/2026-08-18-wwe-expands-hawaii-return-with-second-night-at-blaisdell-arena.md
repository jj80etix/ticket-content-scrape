# WWE Expands Hawaii Return With Second Night at Blaisdell Arena

## Summary

WWE expands its Hawaii return with a second night added at Blaisdell Arena.

### Key Points
- WWE adds a second Hawaii show at Blaisdell Arena.
- Routine event-date announcement, no ticketing/industry-structure angle.

## Transcript

![](https://www.ticketnews.com/wp-content/uploads/2026/08/wwe-hawaii.jpg)

WWE is doubling down on its return to Hawaii.

Following strong demand for its first Honolulu event in seven years, WWE has added a second live show at Blaisdell Arena on Saturday, October 17, extending its 2026 Hawaii Live Tour to two consecutive nights.

The newly announced event follows WWE’s Friday, October 16 show at the venue, which the company says is already nearing a sellout. The two-night run will mark WWE’s first live events in the Aloha State since September 2019.

Both nights are set to feature a lineup of WWE talent including Seth “Freakin” Rollins, The Usos, Jacob Fatu, Oba Femi, Liv Morgan and others.
