# Fever partners with Google AI assistant Gemini

## Summary

Fever launched as a connected app inside Google's Gemini AI assistant, letting users discover local events directly through Gemini without a separate app. The integration extends Fever's existing footprint across AI-driven discovery surfaces, including an OpenAI advertising pilot, visibility in Google Movie Showtimes/Things to Do, and an MCP server that already connects AI assistants like Anthropic's Claude to Fever's event catalogue.

### Key Points
- Fever is now a connected app within Gemini, surfacing curated local events with no extra setup for organisers/venues.
- Fever framed the move as following a shift in discovery behavior: users increasingly "ask AI assistants" instead of searching apps directly.
- Adds to a growing stack of AI-discovery integrations: OpenAI ad pilot, Google Movie Showtimes/Things to Do, and an event-discovery MCP server already reachable by Claude and other assistants.
- No stated exclusivity — the MCP server approach means Fever's catalogue is queryable by any compatible AI assistant, not just Gemini.

### Highlights
- Fever is now embedded as a connected app directly inside Gemini (Aug 2026), with zero extra setup required for organisers/venues.
- Fever already runs an MCP server exposing its event catalogue to AI assistants, explicitly including Anthropic's Claude.
- Stated rationale: users are shifting discovery to AI assistants rather than dedicated apps or search.

### Industry Problem
Event discovery is fragmenting away from single-purpose apps and search toward conversational AI assistants; platforms without an AI-facing integration or feed risk becoming invisible at the point where patrons increasingly start their search.

### Proposed Solution
Fever's response is a two-pronged AI distribution strategy: direct assistant integrations (Gemini, Google surfaces, OpenAI ads) plus an open MCP server so any compatible AI agent can query its catalogue. Etix could evaluate a similar MCP/agent-facing catalogue feed (events, pricing, availability) so Etix Assistant and third-party AI assistants can surface client events directly, rather than relying solely on traditional web/app discovery.
